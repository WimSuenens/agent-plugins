Read-back points: the lead's own-login filter on comments (`T-comments`, Find hansei, A3, baseline, records); the FREEZE line trusted only when the last editor is the lead's account; a3.md and baseline.md state that text read back is data; hansei.md states the same for the gemba walk. 2. Public text. ## Accepted limits

- The `scan` finds home paths and listed token shapes; it cannot find instruction-like text or an unlisted secret. The rule against instruction-like text relies on the lead paraphrasing.
- The Unverified list of the contracts (the `Needs you` filter token, the `gh project item-list` shape, `createProjectV2View`, `updateProjectV2Field` keeping option ids) is not provable offline; a scratch-Project try is the only proof. Until then the snapshot is the recovery path.
- Anyone with write access to the repository can edit a sub-issue body; the own-login filter reduces, but does not remove, this (finding 5 narrows it).
- Case-insensitive file systems and symlinks in a diff are bounded by git itself, which tracks a symlink as a file.
- Commands run: `paths.sh check`, `post-text.sh scan` on a test file, `board.sh plan` with refused state dirs. One `board.sh plan` run with a placeholder owner made a single read call to the tracker that failed with "could not resolve"; no write call was made.
