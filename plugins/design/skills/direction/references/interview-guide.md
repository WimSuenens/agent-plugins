# Interview guide

Question bank for `direction`'s phases 1-2, organized by dimension. Keep
each dimension to 2-4 questions — this is a tight interview, not an
exhaustive checklist. The goal of every question is a *specific, counted*
answer; if the answer comes back as a mood word, ask one forced-choice
follow-up before moving on, don't accept it and continue.

## Concept (phase 1)

2-3 questions, asked before anything else:

- "In one sentence: what's the tension or metaphor this design argues?
  (e.g. restraint vs. richness, instrument vs. software, presence vs.
  absence.)"
- "If this direction had to alternate between two states — light/dark,
  loud/quiet, dense/empty — what are the two states, and what triggers the
  switch?"
- "What's the one thing this design should never be mistaken for?" (forces
  a negative constraint, which is often sharper than a positive one)

**Undecided user / wants multiple candidates:** if the user can't commit
to one concept sentence, or explicitly asks for options, stop pushing for
commitment. Instead ask: "Give me 2-3 different one-sentence concepts,
even rough ones" — then run phases 2 onward *once per concept*, producing
genuinely divergent candidates rather than one concept with three colour
palettes bolted on. Divergence has to show up in every dimension, not just
concept — check this explicitly in phase 3.

## Colour (phase 2)

2-4 questions:

- "Pick an exact number for the whole palette, not counting pure text
  greys — how many colours?"
- "Name what each one is the *only* thing allowed to do. If two colours
  could swap jobs without anyone noticing, you have one colour too many."
- "Where does your one 'precious' colour (if you have one) get spent —
  name the specific elements, not a general category like 'highlights.'"
- "When a card or surface needs to read as distinct from the page behind
  it, what's the rule — a tint, a border, a shadow, the same colour as the
  ground? Pick one mechanism and apply it everywhere."

## Type (phase 2)

2-3 questions:

- "How many typefaces total — one, two, three? No more without a specific
  reason."
- "For each face, what's its one job? If you're tempted to give one face
  two jobs, that's a sign you need a second face instead."
- "Is there a tracking or weight system — exact letter-spacing or weight
  values, each locked to one role (headline, eyebrow, wordmark)? How many
  values, and what's each one's role?"

## Shape & elevation (phase 2)

2-3 questions:

- "Pick one distinctive elevation device — describe it as a recipe: what
  are its required parts, in order?" (push for something implementable,
  not a mood: "a shadow pairing," "a cut corner + one rounded exception,"
  "inset-only recess shadows")
- "Does corner radius vary by role (cards vs. buttons vs. pills) or stay
  uniform? If it varies, name the values per role."
- "What is this device never allowed to combine with?" (e.g. raised and
  recessed shadows on the same object, hard and soft shadows together)

## Motion (phase 2)

2-3 questions:

- "What's the one thing that animates on entrance, once, and never
  repeats within a section? Describe it concretely."
- "How many ambient/looping motion devices — zero, one, or two? Never
  more. Name each one if there are any."
- "What happens under reduced-motion? (Even 'everything becomes a plain
  fade' is a valid, specific answer — just state it.)"

## Voice (phase 2)

2-3 questions:

- "How are section labels formatted — numbered (from where?), slash- or
  symbol-prefixed, plain text? Pick one rule."
- "What's the headline structure — line count, clause count, any
  required visual break between clauses?"
- "How are quantities stated — always exact, always rounded, or a
  specific rule for when each applies? Pick one and hold it everywhere."
- "What's one verbal tic — a construction, a punctuation habit, a
  vocabulary substitution — that shows up nowhere else in this product's
  copy and marks this direction as itself?"

## Handling divergent candidates through phases 3-5

When running 2-3 candidates in parallel: keep a running table (concept /
colour count / type count / shape device / motion device / voice tic) so
you can check at a glance that no two candidates share a value on any
dimension. If two candidates converge on the same colour count or the same
entrance device, that's not really two directions — go back to phase 2 for
the weaker of the two and push for a different specific answer.
